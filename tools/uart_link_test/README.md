# Проверка проводки UART между двумя платами

Отдельный маленький проект ESP-IDF. Это **не** прошивка KeyKeeper2: она нужна только для того, чтобы убедиться, что два провода между платами работают в обе стороны, прежде чем писать поверх них протокол (этап 3).

Одна и та же прошивка заливается на обе платы. Каждая плата раз в 200 мс шлёт пронумерованный пакет, проверяет всё, что приходит, и раз в секунду печатает одну строку с вердиктом.

## Провода

| Плата «Хранилище» | | Плата «Донгл» |
|---|---|---|
| GPIO10 (TX) | → | GPIO11 (RX) |
| GPIO11 (RX) | ← | GPIO10 (TX) |
| GND | — | GND |

Питание 3,3 В между платами не соединять. У каждой платы свой USB-кабель.

## Сборка и прошивка

Из терминала ESP-IDF, в этой папке (`tools/uart_link_test`):

```
idf.py set-target esp32s3
idf.py build
idf.py -p COMx flash monitor
```

`COMx` свой для каждой платы. Откройте два окна терминала ESP-IDF, в каждом свой порт. Выход из монитора: Ctrl+].

Лог идёт через USB самой платы (не через выводы 43/44). Пины, скорость, длину пакета можно поменять в `idf.py menuconfig` → «UART link test».

## Как читать вывод

```
[  5s] tx=26 | rx ok=21 crc_err=0 junk=0 lost=0 bytes=609 | peer=B2B2 | LINK OK
```

| Поле | Смысл |
|---|---|
| `tx` | сколько пакетов отправила эта плата |
| `rx ok` | сколько правильных пакетов пришло от другой платы |
| `crc_err`, `junk` | испорченные пакеты и выброшенные байты (на исправном проводе 0) |
| `lost` | сколько пакетов пропало (по разрывам в нумерации) |
| `peer` | номер другой платы (последние два байта её MAC) |

Вердикты:

| Вердикт | Что значит и что делать |
|---|---|
| `LINK OK` | работает в обе стороны |
| `NO DATA` | по RX ничего не приходит: проверьте скрещивание TX/RX, общий GND, и что на второй плате идёт этот же тест |
| `ONE WAY` | эта плата слышит вторую, но вторая её нет: проверьте провод от TX этой платы к RX второй |
| `GARBAGE` | байты идут, но пакетов нет: разная скорость, TX соединён с TX, длинные или плохие провода |
| `LOOPBACK` | плата слышит сама себя: TX замкнут на RX на этой же плате |

Пока вторая плата выключена, `NO DATA` нормален.

## Проверка одной платой

Соедините перемычкой GPIO10 и GPIO11 на одной плате. Она должна сказать `LOOPBACK`. Это проверяет выводы и UART-контроллер без второй платы. Потом уберите перемычку.

## После проверки

На плату «Хранилище» нужно снова залить прошивку KeyKeeper2 целиком (`idf.py flash` в корне проекта). Этот тест пишет только загрузчик, таблицу разделов и своё приложение в начале флеша. Область хранилища (раздел `storage`, 0x320000) он не трогает, но таблица разделов на время замены другая, поэтому возвращайте основную прошивку полностью, а не по частям.

## Тесты логики на ПК

Логика кадров, счётчиков и вердикта (`main/link_frame.hpp`, `main/link_stats.hpp`) не зависит от ESP-IDF и проверяется на ПК:

```
cd tools/uart_link_test/test_host
bash run_host_tests.sh
```

Ожидается `... checks, 0 failed`.
