Version: 2.0.0

# 1. Purpose

Настоящий документ определяет стратегию разработки проекта **KeyKeeper2**.

Roadmap описывает:

- текущее состояние проекта;
- этапы разработки;
- основные контрольные точки (Milestones);
- последовательность реализации компонентов;
- план выпуска версий.

Документ не содержит технических деталей реализации.

Архитектурные решения описываются в:

- ARCHITECTURE.md
- SOFTWARE.md
- ADR

---

# 2. Project Vision

KeyKeeper2 создаётся как современный автономный менеджер паролей для ESP32-S3.

Проект ориентирован на:

- долгосрочную поддержку;
- открытую разработку;
- качественную архитектуру;
- безопасное хранение данных;
- современный пользовательский интерфейс;
- простоту сопровождения.

Основной целью проекта является создание законченного программного продукта, пригодного для ежедневного использования.

# 4. Development Principles

Разработка проекта выполняется в соответствии со следующими принципами:

- Documentation First;
- Architecture Before Code;
- Component-Based Architecture;
- Event-Driven Architecture;
- Security First;
- Incremental Development.

Каждый новый этап разработки должен завершаться полностью работоспособным результатом.

Любое изменение архитектуры должно сопровождаться обновлением документации и соответствующего ADR.

# 5. Project Milestones

Разработка разделяется на последовательные контрольные точки.

Основные Milestones:

Цель этапа — создать базовую инфраструктуру проекта.

## Tasks

- ScreenManager;

# 10. Phase 5 — Security

Цель этапа — реализовать полноценную подсистему безопасности.

---

## Tasks

Необходимо реализовать:

- SecurityService;
- PinManager;
- LockManager;
- SessionManager;
- PermissionManager.

---

## Features

Поддерживаются:

- PIN;
- Auto Lock;
- Session Control;
- Permission Check;
- Protected Operations.

---

## Result

После завершения этапа все защищённые операции должны проходить через SecurityService.

---

# 11. Phase 6 — USB HID

Цель этапа — реализовать работу устройства как USB HID Keyboard.

---

## Tasks

Необходимо реализовать:

- USBService;
- HID Keyboard;
- Print URL;
- Print Username;
- Print Password;
- Print OTP;
- пользовательские последовательности ввода.

---

## Quick Screen

Необходимо реализовать быстрые действия:

```text
Short BACK → Unlock

Long BACK → Print Password

Short OK → Print URL
```

---

## Result

После завершения этапа устройство должно корректно работать на:

- Windows;
- Linux;
- macOS.

Без установки дополнительных драйверов.

---

# 15. Release Plan

Разработка проекта выполняется поэтапно.

---

## Alpha

Первый внутренний выпуск.

Включает:

- базовую архитектуру;
- GUI;
- Vault;
- Security.

Предназначен исключительно для разработки и внутреннего тестирования.

---

## Beta

Первый функционально полный выпуск.

Включает:

- USB HID;
- Web UI;
- Backup;
- Import / Export.

Основная цель — тестирование полного набора функций.

---

## Release Candidate

Финальная проверка перед выпуском стабильной версии.

Исправляются только ошибки.

Новая функциональность не добавляется.

---

## Version 1.0

Первый стабильный выпуск проекта.

Должны быть завершены:

- документация;
- архитектура;
- реализация всех основных компонентов;
- тестирование.

---

# 16. Long-Term Goals

После выпуска версии 1.0 развитие проекта продолжается.

Планируемые направления:

- AES-256 Encryption;
- Secure Element;
- OTA Updates;
- NFC;
- Bluetooth;
- Plugin System;
- Multiple Vaults;
- Multi-User Support;
- новые языки интерфейса;
- дополнительные темы оформления.

Все новые функции должны интегрироваться без нарушения существующей архитектуры.

---

# Summary

Roadmap определяет последовательность разработки проекта **KeyKeeper2** от завершения проектной документации до выпуска стабильной версии.

Каждый этап завершает логически законченный набор функций и сопровождается обновлением документации, тестированием и проверкой соответствия архитектуре.

Следование данному плану позволяет вести разработку последовательно, минимизировать архитектурные изменения на поздних стадиях проекта и обеспечить высокое качество программного обеспечения.
