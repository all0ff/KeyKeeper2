# Developer Documentation

**Project:** KeyKeeper2

**Version:** 2.0

---

# Purpose

Каталог **docs/developer/** содержит документацию, предназначенную для разработчиков проекта **KeyKeeper2**.

Документы данного каталога объясняют:

* внутреннюю организацию проекта;
* используемые технологии;
* правила разработки;
* взаимодействие компонентов;
* требования к реализации программного обеспечения.

Эта документация является практическим дополнением к архитектурной документации проекта.

---

# Target Audience

Документация предназначена для:

* разработчиков прошивки;
* архитекторов проекта;
* специалистов по сопровождению;
* разработчиков пользовательского интерфейса;
* разработчиков сервисного слоя;
* систем искусственного интеллекта, участвующих в генерации программного кода.

---

# Documentation Principles

Вся документация проекта построена на принципе **Documentation First**.

Это означает:

* сначала принимается архитектурное решение;
* затем обновляется документация;
* только после этого начинается реализация программного обеспечения.

Исходный код не является первичным источником архитектурной информации.

# Development Rules

При разработке необходимо соблюдать следующие правила.

* не нарушать компонентную архитектуру;
* использовать только публичные интерфейсы сервисов;
* не обращаться напрямую к аппаратному обеспечению;
* использовать EventBus для обмена событиями;
* не размещать бизнес-логику в GUI;
* соблюдать требования документа **CODING_STANDARD.md**;
* обновлять документацию перед внесением архитектурных изменений.
