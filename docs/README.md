# KeyKeeper2

> Standalone Password Manager for ESP32-S3

KeyKeeper2 — это автономный менеджер паролей с аппаратным управлением, построенный на базе **ESP32-S3**.

Устройство предназначено для безопасного хранения учётных данных и быстрого ввода их на компьютере с использованием **USB HID Keyboard**.

Все данные пользователя хранятся локально.

Использование облачных сервисов не предусмотрено.

# Quick Start

Минимальные требования для начала разработки:

- Git;
- CMake;
- Ninja;
- Python 3;
- ESP-IDF 5.5.x;
- Visual Studio Code (рекомендуется).

---

## Clone Repository

```bash
git clone https://github.com/<username>/KeyKeeper2.git

cd KeyKeeper2
```

---

## Configure ESP-IDF

```bash
idf.py set-target esp32s3
```

---

## Build

```bash
idf.py build
```

---

## Flash

```bash
idf.py flash
```

---

## Monitor

```bash

```

## Quick Screen

После включения устройства отображается стартовый экран (**Quick Screen**).

Он обеспечивает быстрый доступ к наиболее востребованным действиям.

Поддерживаются следующие команды:

```text
Short BACK → Unlock

Long BACK → Print Password

Short OK → Print URL
```

Quick Screen не предоставляет доступ к данным пользователя без прохождения проверки безопасности.

---

## Security

Подсистема безопасности является отдельным компонентом проекта.

Все операции, связанные с доступом к защищённым данным, выполняются через **SecurityService**.

Поддерживаются:

- PIN;
- Auto Lock;
- Session Management;
- Permission Management;
- Protected Operations.

Security реализован как самостоятельный компонент и не зависит от GUI, USB или Web UI.

# Summary

**KeyKeeper2** — это автономный менеджер паролей для **ESP32-S3**, построенный на принципах **Documentation First**, **Component-Based Architecture**, **Event-Driven Architecture** и **Security First**.

Проект сочетает современную программную архитектуру, модульную структуру компонентов, локальное хранение данных и подробную документацию, что делает его удобным для разработки, сопровождения и дальнейшего развития.

Основной целью проекта является создание надёжного, безопасного и полностью автономного устройства для хранения и быстрого использования учётных данных без зависимости от внешних облачных сервисов.
