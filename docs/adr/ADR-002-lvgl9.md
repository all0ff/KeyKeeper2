# ADR-002 — LVGL 9

**Status:** Accepted

**Date:** YYYY-MM-DD

**Version:** 2.0

---

# Context

Проект **KeyKeeper2** использует графический пользовательский интерфейс (GUI) для взаимодействия с пользователем.

Интерфейс должен обеспечивать:

* высокую производительность;
* поддержку аппаратных дисплеев ESP32-S3;
* современный внешний вид;
* поддержку тем оформления;
* гибкую систему виджетов;
* масштабируемость;
* возможность дальнейшего развития интерфейса.

При выборе графической библиотеки рассматривались различные варианты, включая собственную реализацию GUI и сторонние решения.

---

# Decision

В качестве единственной графической библиотеки проекта принято решение использовать **LVGL 9 (Light and Versatile Graphics Library)**.

Все элементы пользовательского интерфейса должны разрабатываться исключительно средствами LVGL.

Использование других GUI-фреймворков в проекте не допускается.

---

# Rationale

Использование LVGL 9 обеспечивает следующие преимущества:

* официальную поддержку современных возможностей библиотеки;
* высокую производительность на ESP32-S3;
* компонентную архитектуру пользовательского интерфейса;
* поддержку аппаратного ускорения отображения;
* встроенную систему тем оформления;
* богатый набор стандартных виджетов;
* поддержку анимаций;
* активное развитие и долгосрочную поддержку сообщества.

LVGL хорошо интегрируется с ESP-IDF и соответствует архитектурным требованиям проекта.

---

# Consequences

После принятия данного решения:

* все экраны создаются средствами LVGL;
* навигация реализуется через ScreenManager;
* темы оформления используют механизм Theme Manager;
* отображение выполняется только через API LVGL;
* пользовательский интерфейс отделён от бизнес-логики и взаимодействует с системой через EventBus и сервисный слой.

Это обеспечивает единообразие реализации интерфейса и упрощает его сопровождение.

---

# Alternatives Considered

## Собственная GUI-библиотека

Преимущества:

* полный контроль над реализацией;
* отсутствие внешних зависимостей.

Недостатки:

* большой объём разработки;
* необходимость самостоятельно реализовывать виджеты, анимации и систему отображения;
* высокая стоимость сопровождения.

Данный вариант признан нецелесообразным.

---

## Другие графические библиотеки

Рассматривались альтернативные решения, однако они не обеспечивали такого уровня интеграции с ESP32-S3 и ESP-IDF, как LVGL.

Кроме того, большинство альтернатив имеют меньшую функциональность либо менее активную поддержку сообщества.

# Summary

Проект **KeyKeeper2** использует **LVGL 9** в качестве единственной графической библиотеки.

Это решение обеспечивает современный пользовательский интерфейс, высокую производительность, удобство сопровождения и полную совместимость с архитектурой проекта на базе ESP-IDF.
